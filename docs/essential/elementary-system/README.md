# 🚀 别慌！计算机其实很好懂

> 给数字时代新手的生存指南 —— 让你的手机和电脑不再神秘兮兮！

如果你符合以下任何一条：
- 手机玩得飞起，打开电脑连文件都找不到
- 每次装软件都小心翼翼，怕点什么奇怪的东西
- 不明白为什么同一个 Wi-Fi，手机能连但电脑不行
- 觉得"系统更新"弹窗是个需要认真对待的选择题
- 看到命令行就想起电影里的黑客

这门课就是写给你的。不需要任何基础——我们假设你唯一的数字设备经验是手机，而且只是"会用"，不明白原理。

## 学完你能干什么

- **电脑卡/ Wi-Fi 断 / 文件找不到**——知道怎么排查，不用次次求人
- **几十个账号密码**——知道怎么管，不再靠"全部设为同一个密码"
- **想学编程 / 剪视频 / 做设计**——这套常识是地基，没有它你后面会一直卡
- **被推荐算法喂得死死的**——理解它的逻辑，你才能反过来控制它

## FAQ

**Q：我真的零基础，能学会吗？**

A：这门课就是为纯小白设计的。如果遇到不懂的，往下看，答案大概率在后面。

**Q：需要什么设备？**

A：有手机 + 任意一台电脑就够了。没有电脑？手机也能学懂大部分概念。

**Q：学完能当程序员吗？**

A：不能直接变程序员。但如果你想学编程，这是最好的起点——我们打的是地基，不是装修。

**Q：为什么不用"专业术语"？**

A：术语是学习的结果，不是起点。先理解概念，术语自然就会了。记不住也没关系，用大白话描述清楚意思才关键。
